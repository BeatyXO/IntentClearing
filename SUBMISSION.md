# Submission draft

**Title:** IntentClearing — Semantic-Profile Batch Clearing Primitive

IntentClearing is a reusable GenLayer Intelligent Contract for markets where offers and requests contain qualitative requirements that ordinary order books cannot compare safely. A market first seals a bounded semantic attribute dictionary. GenLayer consensus then profiles each order independently against that dictionary; validators reproduce the same bounded masks, while ambiguity fails closed. Crucially, the LLM never compares two orders and never chooses winners. Compatibility, price checks, preference scoring, priority, partial quantities, fills, epoch commitment, and settlement roots are deterministic. Frozen batches receive an epoch hash, and every fill pins both that hash and the immutable market definition. A second `ClearingGate` contract demonstrates typed IC-to-IC consumption with party binding and replay protection. The primitive can support service procurement, compute markets, grants, agent commerce, specialized datasets, and other qualitative order books without reducing the protocol to “AI decides the match.”

Local verification passes repository preflight, Python compilation, 8 static/unit tests, and 26 pinned Direct Mode tests. IntentClearing is finalized on stable Studionet (chain ID 61999), and market 1 plus one semantic attribute are finalized; the remaining live market and ClearingGate lifecycle is pending wallet unlock. The dedicated public repository is [BeatyXO/IntentClearing](https://github.com/BeatyXO/IntentClearing); the tested local commit is not yet pushed because GitHub requires the `workflow` OAuth scope to publish the repository’s CI file. Exact verified evidence is in `DEPLOYMENT.md`.
